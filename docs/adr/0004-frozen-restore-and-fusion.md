# 冻结内容、保守恢复与属性融合证据

日期：2026-11-07。状态：采用；PC09、PC16 的冲突与证据保留策略已经用户确认。

## 本体恢复和历史读取

新增恢复入口与原有“复用已存在资源进行装配”入口分开。恢复先解析、校验依赖闭包
并返回内容摘要，应用时重新解析和检查冲突，只在一个事务中创建并发布。
资源 IRI 保留，本体、资源、字典在目标安装中获得本地版本号；导出文件里的数据库 ID
不作为跨安装身份。现阶段拒绝任何已存在的资源 IRI 或机读名，不自动覆盖或猜测复用。

恢复能力按完整支持的 RDF 子集定义。任何未消费的三元组、不支持的规则、命名图或
无法保证再导出的角色都会阻止应用；不把部分写入作为“完整恢复成功”。外部 JSON-LD
上下文与 OWL imports 不进行网络解析。请求上限为 64 KiB、解析上限为 2,000 三元组。

新发布资源递归冻结其拥有的属性与关联资源版本；新发布本体保存规则正文和依赖闭包。
历史接口只读取固定版本的快照，不回填、重写旧记录或读取当前资源作为缺失历史的替代。
旧规则没有正文时显示 UNAVAILABLE；缺少必要资源快照时显式失败。

## 属性融合

业务键映射必须显式设置来源优先级、空值处理和冲突策略；更小的数值表示更高优先级。
同类型的来源共享空值/冲突策略，拥有稳定源行键。最高优先级不同值、重复源身份的
矛盾值，以及选用隔离策略时的不同值，都隔离整个实体及其关系。
无有效业务键的源行不允许在关系阶段重新生成占位实体。

选值不依赖读取顺序。相同来源、相同输入和值合并计次；不同原值转换成同值时仍保留
各个原值。仅记录映射涉及的列，保存输入值、转换后候选值、来源连接/表/行键/列、
优先级、是否选用、最终值及原因，不复制完整源行或数据源凭据。

证据保存于对应运行的 `cfg_snapshot.fusion_evidence`，格式版本为 1；映射策略也随
映射版本冻结。历史解释只读运行快照，不回查当前源行补造历史。被隔离实体可通过
原图谱版本和 IRI 查询原因。证据沿用现有图谱读取权限和运行生命周期。

旧运行缺少证据时显示 LEGACY/UNAVAILABLE。旧业务键映射可读、可复制，重新运行前
必须配置显式策略；增量追加与业务键融合仍不支持，不能绕过失败保护。
AI 建议追加映射时使用完整契约解析已有草稿，保留融合策略、转换和关系端点配置。

## 语义视图

模板在既有 JSON 配置中保存 `semantic_version: 1` 与层级关系、度量、时间和经纬度 IRI，
同时固定适用本体版本。候选目录来自冻结快照，布局实际消费配置，不从任意字段名猜测。
时间采用明确的 UTC ISO 日期，地理使用 WGS84 数值坐标；没有结束时间时不虚构甘特区间。
同名属性只有在实例适用类型内对应唯一 IRI 时才允许机读名回退；否则要求精确 IRI。

以上 JSON 扩展不迁移或补写真实历史数据。独立数据库恢复、失败回滚、冻结读取和
融合顺序/隔离的测试，以及实际浏览器操作范围，记录在审计续办报告中。
