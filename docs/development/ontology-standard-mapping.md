# GB/T 48000.3—2026 能力映射

核验日期：2026-11-21，基线 `17de2e6`。本页记录通用建模能力与 GB/T 48000.3—2026 的条款对照，供评估标准符合性时使用。它不声明产品已通过标准认证，也不代表标准核心规范包已随应用交付。

## 判定口径

`DIRECT` 表示当前模型或页面直接表达了该要求，不表示完整标准认证；`GENERIC` 表示只有通用机制，没有标准语义；`MISSING` 表示没有可验证能力；`NO_UI` 表示属于模型、序列化、推理或校验，不需单独页面。

## 主要缺口

1. 标准核心实体未作为一等模型提供：当前只有通用实体类型能力。
2. 标准实体、标准化对象、相关方、领域类别、要素、层次、技术内容与制定程序没有固定 IRI、定义、属性与关系集合。
3. 表1的 34 个核心对象属性没有标准化落地。
4. `owl:hasKey`、通用唯一元组、日期先后、替代链、无标题条结构限制等 8.2 核心规则未形成完整闭环。
5. 带 OWL/SHACL 治理规则的本体无法通过完整恢复器无损往返。

## 结论与使用边界

通用模型、RDF/OWL/SHACL 子集与版本冻结已实现，因此 5.2、5.3、5.4、7.1–7.3.1、8.1 等条款可判为 `DIRECT`；但 6.2 核心模型、表1 核心对象属性、部分 8.2 规则与完整交换仍缺失，整体只能表述为**部分符合**，不能写成通过认证或已提供标准 Profile。

差异项如需落地，按[文档同步规范](../../.agents/conventions/documentation.md)登记功能编号、实现与测试，并补充相应验证；本页作为评估基线，不替代业务验收。当前能力边界见[能力限制](../product/limitations.md)。
