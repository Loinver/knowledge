## 仍未实现或仅部分实现的能力

- 业务审计的上述间接/后台写入覆盖：需显式传递真实操作者及资产目标，不能归因给最后访问者；已有直接端点的事件不能证明这些入口已留痕。
- 跨进程任务取消：当前仅本进程控制器有效，找不到工作进程时明确返回不可用。
- 增量抽取当前限定追加模式，不支持源行更新、删除和业务键融合；有影响旧图的数据条件应拒绝，而非当作增量成功。
- 自动抽取阶段的完整 SHACL/OWL 执行、完整 OWL DL、周期调度及文档候选事实入库仍按原规划单独验收；未执行仍必须为 NOT_RUN。
- 大目录远端筛选/虚拟化及所有图形增强不是“拉全目录”或代表性布局回归的同义词。
- 普通列表及图谱附加请求的剩余异步风险尚未逐项核实，保留待核验性质，不按已证实缺陷计数。

## 仍需真实环境验证

- PostgreSQL 元数据库的锁、事务、超时、迁移及并发；本轮真实事务/进程回归以隔离 SQLite DELETE/WAL 为主，PostgreSQL 分支仅代码/契约检查。
- PostgreSQL/MySQL 源库的实际只读连接、权限、连接释放与负载行为。
- 不支持 Web Locks 的浏览器跨标签刷新；Chromium 双标签不能代表所有浏览器。
- 全部 32 图形的大数据、键盘操作、英文长文本、缩放与语义字段覆盖。
- 外部 LLM、生产安装/恢复、远端 CI、生产容量/SLA、标准全文符合性。
