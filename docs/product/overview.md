# 产品介绍与业务价值

核验日期：2026-11-26；代码范围与验证分层见[核验记录](../maintenance/verification-2026-11-26.md)。

## 产品定位

知识中台是面向企业知识建模、数据转化和证据管理的自托管应用。它以可复用的语义资产定义业务概念，通过本体与映射约束数据进入图谱的方式，再用运行记录、校验结果和来源证据解释结果。独立的文档知识库提供文档处理、检索、证据摘录问答和图事实人工关联。

平台的交付价值是让建模人员、数据工程人员、业务分析人员和治理人员在同一条可核查链路上协作。当前代码已有端到端流程，但不代表已经具备多租户 SaaS、行业认证或生产服务等级承诺。

## 适用场景

以下为产品使用方式示例，均使用虚构业务，不代表已交付客户案例。

| 场景               | 用户要解决的问题                           | 在平台中的处理方式                                     | 可交付结果                           |
| ------------------ | ------------------------------------------ | ------------------------------------------------------ | ------------------------------------ |
| 企业与人员关系     | 不同表中的企业、人员和任职关系缺少统一定义 | 定义类型与关系、按业务键映射、抽取并探索邻域           | 具有运行批次与来源行证据的关系结果集 |
| 组织、客商与合同   | 同一主体跨表出现，需要解释融合与关联       | 配置身份规则和融合策略，检查校验与隔离结果             | 可追踪来源贡献的实体与事实           |
| 标准与规则治理     | 不同模型对词汇、约束和条款理解不一致       | 管理命名空间、枚举、规则及条款关联，执行明确范围的校验 | 四态报告和版本化治理资产             |
| 制度与业务资料检索 | 文档难查，答案缺乏可定位出处               | 上传受支持文档、建立索引、检索原文片段与引用           | 可查看原文位置的检索结果和证据摘录   |

## 能力组织

1. **语义层**：命名空间、实体类型、关系类型、业务域、枚举、模板和本体。
2. **数据层**：只读连接、元数据、样例预览、映射发布、抽取任务和运行。
3. **知识层**：图谱结果集、实体与事实、来源证据，以及文档知识库和检索。
4. **治理与管理层**：规则、校验、历史与审计、用户角色、模型配置和账户安全。

工作台显示已有统计、当前结果集和关键入口。统计不是流程审批状态，也不是个人任务分配系统。

## 协作与交付边界

系统采用 ADMIN、EDITOR、VIEWER 全局角色，具体操作以[权限说明](../user-guide/roles-permissions.md)为准。图谱与文档库目前不提供按租户或逐库划分的独立授权域。

版本冻结用于稳定上下游引用；不能据此推导所有接口都采用同一种乐观锁。文档明确区分发布版本、编辑修订、画布布局和当前结果集。

平台保留标准条款编号及自撰说明用于规则关联，不把标准映射、测试通过或四态报告描述为第三方认证。详细能力、限制和核验证据分别见[功能台账](feature-catalog.md)、[限制与评估清单](limitations.md)和[本轮验证](../maintenance/verification-2026-11-26.md)。
