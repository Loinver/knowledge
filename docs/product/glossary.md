# 术语与对象关系

核验日期：2026-11-26；适用基线见[核验记录](../maintenance/verification-2026-11-26.md)。

| 术语                   | 在本产品中的含义                                     | 容易混淆的边界                               |
| ---------------------- | ---------------------------------------------------- | -------------------------------------------- |
| 命名空间               | 组织资源 IRI 的前缀与基础地址                        | 不是租户或数据权限边界                       |
| 实体类型               | 对企业、人员等一类对象及其属性的定义                 | 不等于抽取后的某个企业实例                   |
| 关系类型               | 对实体之间关系及端点约束的定义                       | 有属性的关联记录不能简单去重成一条边         |
| 业务域                 | 对语义资产的业务组织与关联                           | 不代表独立租户或隔离库                       |
| 本体                   | 由成员类型、关系和约束组装的语义模型                 | 发布时固定引用的资源版本                     |
| 发布版本               | 可被下游明确引用的历史版本                           | 新草稿不自动替换已经冻结的下游引用           |
| 编辑修订               | 用于识别当前可编辑对象状态的修订号                   | 不等于发布版本号；实际并发参数见接口契约     |
| 映射                   | 源表、字段与语义对象、关系之间的配置                 | 发布映射固定本体版本，预览不等于执行成功     |
| 业务键                 | 构造实体身份或执行融合时采用的业务字段               | 不一定等于源表技术主键；必须按场景保证稳定   |
| 增量水位               | 增量读取所依据的字段和进度                           | 不是数据库日志 CDC，也不等于定时调度         |
| 抽取任务               | 基于发布映射提交的一次立即或延后执行请求             | 任务定义、某次运行、运行产生的结果集不同     |
| 运行                   | 一次执行及其状态、统计、异常与证据                   | 失败运行不能被当成成功结果集                 |
| 图谱结果集             | 一次成功产出的可选择图谱版本                         | 当前指针可以切换，历史版本仍是历史版本       |
| 事实                   | 图谱中实体属性或关系的业务断言                       | 可对应多个来源贡献，来源记录需结合结果集解释 |
| 证据                   | 事实的来源连接、表、行键、字段或执行上下文           | 文档人工关联不自动成为抽取来源证据           |
| 隔离记录               | 未进入正常结果的异常记录及理由                       | 存在隔离不等于整次运行必然失败，取决于策略   |
| 校验四态               | PASS 通过；VIOLATION 违反；NA 不适用；NOT_RUN 未执行 | 未执行不能显示为通过；总分不能替代逐项结论   |
| 知识库                 | 文档、处理任务及检索范围的组织单元                   | 当前采用全局角色，没有逐库 ACL               |
| 活动索引               | 文档当前用于检索的成功处理结果                       | 重处理失败不应使上一成功索引消失             |
| 关键词／语义／混合检索 | 词项匹配、向量相似度、组合排序三类方式               | 语义能力依赖可用的向量服务及匹配的索引版本   |
| 证据摘录问答           | 依据检索证据返回可定位原文引用                       | 不是任意事实生成或无限制外部知识问答         |
| 模型能力               | CHAT 对话与 EMBEDDING 向量服务配置                   | 保存配置不等于连接测试或模型效果验收         |

阅读顺序：[建模与治理](../user-guide/modeling-governance.md) → [数据到图谱](../user-guide/data-graph.md) → [知识库与系统](../user-guide/knowledge-system.md)。
