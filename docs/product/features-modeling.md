## 实际权限与并发契约

权限真值源为 [server/app/main.py](../../server/app/main.py) 的业务路由挂载及 [server/app/api/v1/deps.py](../../server/app/api/v1/deps.py)。本范围没有按租户/业务域配置的对象 ACL；大多数业务接口采用全局角色。VIEWER 可读，EDITOR/ADMIN 可写；规则试跑 POST 是逻辑只读例外，校验报告运行、导入预览、模板核心检查与 AI 生成均不在该例外中。AI 建模提案另限创建者；旧 AI 补全建议并无同等私有读取边界。

[API规范](../../.agents/conventions/api-contract.md)已同步区分当前实现与新变更要求。下表记录实际端点差异。

| 操作范围                                | 实际客户端参数                                                                  | 实际保护与缺口                                                                                             |
| --------------------------------------- | ------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 实体/关系 PUT                           | **请求体** `if_match` 必填；`edit_revision` 可选                                | 原子条件更新校验 DRAFT、发布修订和编辑令牌；省略编辑令牌仅按 0 匹配，不是任意草稿兼容                      |
| 实体/关系 rename                        | 仅请求体 `name`                                                                 | 草稿/IRI 校验；无客户端修订令牌，未见递增 edit_revision 或同步 Rule.revision；这是风险，不是已复现故障     |
| 实体/关系 publish / unpublish           | 无 If-Match                                                                     | 按状态原子竞争并推进编辑令牌；不能检测客户端以哪个旧页面内容确认发布                                       |
| 实体/关系 DELETE                        | 无 If-Match                                                                     | 未发布、历史与引用保护；无客户端乐观锁                                                                     |
| 业务域/本体 PUT                         | 请求体 `if_match` 必填、`if_edit_match` 可选                                    | 发布修订与编辑令牌分开；省略编辑令牌不会检测同一发布版内的旧编辑上下文                                     |
| 业务域成员/本体普通 refs POST           | 请求体 `if_edit_match` 可选                                                     | 写时锁父对象并推进令牌；未提供令牌不做客户端旧值比较                                                       |
| 成员/refs DELETE、域/本体 publish       | **头** `If-Edit-Match` 可选                                                     | 比较编辑令牌并锁父对象；不是 If-Match                                                                      |
| 本体 domain-members POST                | 请求体 `if_edit_match` **必填**                                                 | 同时指定 `domain_id/domain_revision`，预检整组版本并原子装配                                               |
| 业务域/本体 DELETE、namespace 创建/删除 | 无客户端修订参数                                                                | 各有存在性/引用/层级/保护校验，不能概括成全局乐观锁                                                        |
| canvas GET/PUT                          | 无客户端修订参数                                                                | 布局不推进语义/编辑版本；并发保存最后写入覆盖；首次 GET 可建空布局并提交                                   |
| 规则/条款/字典/模板更新和删除           | **头** `If-Match` 必填                                                          | 分资源条件更新/锁；模板 copy/instantiate、规则 test 也要求该头；新建及模板 from-ontology/core-check 不要求 |
| RDF 草稿引用 import                     | **头** `If-Match` 必填（允许 0）；`If-Edit-Match` 可选                          | 应用时重新预览、校验目标 DRAFT 与冲突决策                                                                  |
| 完整 restore                            | 请求体 `preview_digest`                                                         | 绑定文件及已观察状态，锁定后重检；不是客户端版本头；仅新建，不覆盖                                         |
| AI 建模                                 | 生成/应用用 `Idempotency-Key`；候选修改、validate/discard/apply 用头 `If-Match` | 应用再校验草稿编辑令牌、上下文、候选与计划摘要、报告、人工确认；有结果未知及回执恢复路径                   |
| AI 补全、运行校验                       | 无统一 If-Match                                                                 | 补全由服务端基线与状态竞争保护；校验生成与输入绑定的持久报告                                               |

## 数组与分页差异

“数组”指成功外壳的 `data` 是数组，绝不表示所有 HTTP 响应都是裸数组；下列接口与分页对象需分别消费。

| 范围                                                                            | 后端实际响应 data                                 | 页面/客户端实际行为                                                                                                                                         |
| ------------------------------------------------------------------------------- | ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| domains / entity-types / relations / ontologies 列表                            | 数组；支持 q/page/page_size，路由丢弃领域层 total | [web/src/api/pagination.ts](../../web/src/api/pagination.ts) 按 200 条逐页收集，未指定 page 时拉完整目录；页面还会做本地筛选/分页，不能宣称全部纯服务端分页 |
| entity-types/stats                                                              | 统计对象                                          | 独立库级计数，不能拿当前列表页计数替代                                                                                                                      |
| namespaces 列表                                                                 | 不分页数组                                        | 前端直接读取清单                                                                                                                                            |
| 域 members、本体 refs/rules/conflicts、字典 revisions/references                | 数组                                              | 不是带 total 的分页集合                                                                                                                                     |
| governance rules / clauses / templates / enum-dictionaries、templates/resources | `{items,total,page,page_size}`                    | 显式分页、按各模块支持的查询/排序字段消费                                                                                                                   |
| AI modeling proposals                                                           | `{items,total}`；请求有 page/page_size            | 不是全字段统一分页响应；单提案/回执为对象                                                                                                                   |
| 旧 AI suggestions                                                               | 不分页数组                                        | 可按 kind/status 筛选，未见创建者隔离                                                                                                                       |
| 冻结版本 contents、validation reports                                           | 聚合/报告对象；结果明细为数组                     | 未发现全历史本体版本/全历史校验报告分页列表 API                                                                                                             |

额外契约差异：[server/app/api/v1/domains.py](../../server/app/api/v1/domains.py) 的域 publish 当前直接返回 `{revision,edit_revision}`，没有声明 `ApiResponse` 响应模型；普通 JSON 外壳不能写成此模块无例外事实。RDF 与报告下载是明确的文件响应。以上属于源码审查发现，本轮没有实际 HTTP 回放。
