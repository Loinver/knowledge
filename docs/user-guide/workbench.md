# 工作台、导航与工作区

核验日期：2026-11-26；对应功能 APP-001、APP-002、APP-003。全部操作以登录角色及服务端授权为准。

## 看清当前工作

工作台 `/` 面向所有已登录用户，汇总实体类型、关系类型、业务域、本体、数据源、映射和运行数量，并显示当前图谱结果集、结果集总量、当前运行隔离量及草稿数量。

进入后先看当前结果集：没有结果集时从建模与数据接入开始；已有结果时可继续探索图谱。隔离数量对应当前图谱关联运行，不是全平台全部异常累计；草稿数也不是分配给你的待办。统计加载失败时使用页面重试，不能把错误视为零数据。

## 找到功能入口

左侧模块轨道负责业务大类，模块内导航负责该模块的页面。顶栏面包屑说明页面归属，页面标题说明当前对象或任务。详情页可能不在菜单中，需从列表进入。

使用顶栏“搜索页面”或 Ctrl/⌘+K 搜索可访问的功能入口，方向键选择、Enter进入。它是页面导航搜索，不检索图谱实体或知识文档内容；业务搜索在对应模块进行。模态编辑期间快捷搜索不会替换正在操作的表单。

主题与语言通过顶栏切换，设置保留在当前浏览器。不同设备或隔离浏览器上下文不会自动同步这些偏好。中英文界面不等于自动翻译业务标签；业务资产的双语字段由维护人员提供。

## 使用密集列表与画布

- 语义资产可按业务域定位，再搜索列表并查看相邻详情；窄屏使用详情抽屉。详情和完整编辑入口以页面提供的实际操作为准。
- 本体设计器与图谱把资源、画布和属性检查器分开；先选择对象，再查看其可用操作。焦点模式扩展工作区，退出后回到原页面操作位置。
- 普通滚轮用于平移画布；Ctrl/⌘+滚轮与显式按钮用于缩放。图谱数据过滤和视图缩放是不同动作。
- 列表为空时先区分“没有任何记录”与“筛选后无匹配”；不要反复创建对象来排查筛选问题。

## 权限、失效与错误页

未登录访问受保护页面会转到登录，登录后按合法目标返回。管理员页面由导航和路由守卫限制，最终仍由 API 鉴权。无权限时进入403页面；不存在的地址进入404页面。会话失效后重新登录，不要通过改变浏览器存储尝试恢复权限。
