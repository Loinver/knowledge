# 角色、权限与访问边界

核验日期：2026-11-26；适用当前全局账号模型。界面隐藏入口不是安全边界，最终以服务端鉴权为准。来源：[业务授权](../../server/app/api/v1/deps.py)、[路由挂载](../../server/app/main.py)、[账号服务](../../server/app/domain/account_service.py)、[权限测试](../../server/tests/test_permissions_matrix.py)。

## 当前角色矩阵

| 操作                                                    | VIEWER             | EDITOR             | ADMIN              |
| ------------------------------------------------------- | ------------------ | ------------------ | ------------------ |
| 工作台、资产、本体、目录、映射、运行、图谱和证据读取    | 可                 | 可                 | 可                 |
| 资产/本体/映射创建编辑发布、数据源维护                  | 不可               | 可                 | 可                 |
| 抽取、任务取消、设置当前结果集                          | 不可               | 可                 | 可                 |
| 编译映射预览、执行校验报告、元数据采集                  | 不可               | 可                 | 可                 |
| 临时连接测试、样例预览、治理规则试跑                    | 可，受端点参数限制 | 可                 | 可                 |
| 已保存数据源连接测试（写入状态）                        | 不可               | 可                 | 可                 |
| 知识库/文档/原文读取、搜索、摘录问答                    | 可，依赖能力可用   | 可                 | 可                 |
| 知识库/文档上传、维护、归档、恢复、重处理、人工图谱关联 | 不可               | 可                 | 可                 |
| RDF恢复/导入预览与应用、模板核心检查、AI生成/应用       | 不可               | 可，受对象状态限制 | 可，受对象状态限制 |
| 个人资料与本人改密                                      | 可                 | 可                 | 可                 |
| 用户管理、角色页、账号/资产审计、模型配置               | 不可               | 不可               | 可                 |

多数业务读取受全局角色开放；无租户隔离、业务域/逐知识库ACL或字段级权限。VIEWER可读源数据样例与文档原文，不能将其等同“只能看脱敏统计”。归档只改变业务活动状态，不是撤销已有读取权限或销毁文件。

## 只读POST与特殊边界

VIEWER的只读POST白名单：临时 `/datasources/test-connection`、`/datasources/preview`、规则 `/{id}/test`、知识库 `/{id}/search` 与 `/{id}/answer`。编译预览、生成校验报告等会持久化，不在白名单。方法为GET也不能推导系统绝对无副作用，例如首次画布布局读取可能创建空布局。

AI业务建模候选绑定创建者，按提案权限处理；旧AI补全建议没有同等创建者私有读取边界。对象发布冻结、引用约束、修订冲突与权限是不同条件：ADMIN拥有角色权限也不能绕过业务约束。

## 账号状态与恢复

公开注册默认关闭；开启后新账号为VIEWER。首个ADMIN仅由空账号库初始化创建；之后ADMIN发放账号。角色为固定枚举，角色页只有查看与人数，没有在线自定义授权。

禁用账号撤销会话；管理员不能自禁用或自降级。个人改密需要旧口令；一次性重置由管理员为其他活动用户签发，重置后旧会话失效。没有邮件找回、SSO、MFA或外部身份联邦。失去唯一管理员访问时没有产品内自助恢复入口，见[故障排查](../operations/troubleshooting.md)。

## 验证状态

本轮浏览器验证了知识库VIEWER限制及账号/管理员部分流程，相关页面的导航与403入口也做了抽查；不是全权限矩阵、所有越权组合或安全认证。测试文件存在性与执行范围分开记录在[核验记录](../maintenance/verification-2026-11-26.md)。权限或认证代码变化时同步本表、对应功能台账、账户指南和部署说明。
