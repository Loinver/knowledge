## 当前证据与设计决定

- 初始锁文件解析 Vue 3.5.43、TypeScript 5.7.3、Vite 6.4.3、Naive UI 2.45.3。当前保留 Vue/TypeScript/Vite，Naive 运行时与主题适配已移除；新增精确依赖见 dependencies.md。
- 运行时 UI 涉及工作台、语义资产、本体、数据接入、图谱、治理、知识库、账户、系统和认证页面。
  初始导入盘点：Button 60、Alert 57、Input 38、FormItem 36、Select 33、DataTable 21、Drawer 19 个消费者。
- 侧栏品牌行 76px，顶栏 50px；采用一个 `header-height` token 对齐两者。
- 当前 `--accent` 是主操作色。shadcn 的 accent 表面必须独立映射，不覆盖现有图谱和链接语义。
- 现有全局 token 同时包含 reset、工具类和 Naive 内部选择器；分离为 token、全局基础样式和组件样式。
- 现有知识库接口返回真正的 `items/total/page/page_size`，支持服务端 q/status/sort。
  实体类型列表返回数组，现有客户端会逐页读完整集合；其状态/违反筛选是本地筛选。
  迁移显式标记本地集合能力，不能将集合长度称为远程 total，也不擅自增加后端契约。

## 视觉和布局

采用中性表面与一个明确主操作色，AI、图谱和业务状态保持专用颜色。
桌面为固定导航、等高顶栏和独立内容滚动区；满幅图谱/建模页面不重复应用页面 padding。
正文 14px、辅助文字 12–13px、控件 36px、普通行最小 44px、双行对象 48px。
间距沿 4px 基准；标题与工具条允许换行，主要操作始终可达。
暗色靠表面和边框分层；浅色使用克制阴影。焦点、禁用、选中、加载和错误采用同一规则。
长 IRI 可完整查看/复制；宽表格有界滚动，真实操作列固定到右侧。
长弹层限制为视口内尺寸，内容独立滚动，底部操作区稳定可用。
图谱无选择时隐藏空检查器；工具条和图例不过度占用画布。

## token 真值源与主题

唯一值来源为 `web/src/styles/tokens.css`。Tailwind/shadcn/业务组件/SVG 只引用语义变量。
覆盖表面、文字、操作色、状态、图语义、间距、排版、尺寸、边框、圆角、阴影、焦点、层级、动效和断点。
旧 token 以别名保持过渡兼容；映射核对语义后进行，最终页面改用规范 token。
继续使用 `useUiStore` 的 `ThemeMode`、`kg-theme-mode` 和 `html[data-theme=dark]`，不引入另一套主题 store。
Tailwind 使用显式层级；全站迁移期间不引入会重置旧页面的完整 Preflight。
基础 reset 在统一入口明确维护，避免全局样式不可预测覆盖。
完整 token 清单见 [tokens.md](./tokens.md)。

## 源码边界和维护路线

| 层             | 归属                           | 职责                                                          |
| -------------- | ------------------------------ | ------------------------------------------------------------- |
| 上游基础原语   | `web/src/components/ui/`       | shadcn-vue 源码与 Reka 交互，尺寸/变体/键盘/焦点，无领域依赖  |
| 跨业务组件     | `web/src/components/business/` | 表单、字段、操作栏、搜索和受控表格，通过 props/emits/插槽协作 |
| 跨业务组合逻辑 | `web/src/composables/`         | 已有请求失效与草稿保护；至少两个业务域证实需求后共享          |
| 领域私有能力   | `web/src/views/<area>/`        | 字段、权限、请求、路由、对象与 revision 归属                  |
| 应用壳         | `web/src/layout/`              | 导航、顶栏、认证壳和滚动边界                                  |

基础原语以官方 Vue/Reka 路线维护，版本及源码许可记录在依赖文档。
项目门面只做明确的尺寸、变体、受控输入和反馈契约，不模拟领域服务，也不保留 Naive 运行时。
升级先比较上游变更，再应用本地 token/i18n/焦点修改，跑实际消费者的回归；不无审查覆盖本地源码。
