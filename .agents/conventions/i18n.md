# 国际化（i18n）约定

本项目默认中文、支持英文。**只做界面翻译是不够的**——如果本体建模出来的类型、属性定义仍是中文，
英文用户看到的是「英文外壳 + 中文内核」。所以分三层，缺一层都不算完成。

## L1 · 界面文案（vue-i18n）

- 语言包：`web/src/locales/zh-CN.json`、`web/src/locales/en-US.json`，默认 `zh-CN`。
- 语言切换存 localStorage，未设置时按 `Accept-Language` 回退。
- **禁止模板裸文本**：`@intlify/vue-i18n/no-raw-text` 是 error 级，会直接拦截。
  例外是按配置白名单的符号（`-` `·` `:` `|` `/` `&nbsp;`）。
- i18n key 用点分小写、按页面分组：`type.detail.props.range`。
- 日期/数字走 `Intl`，随语言切换。
- CI 检查两份语言包 key 集合一致；缺失的英文键必须在 UI 上标「未翻译」，不能静默回退中文——这与校验四态同源的诚实原则。

## L2 · API 消息与枚举

- 后端**永不返回面向用户的中文句子**，只返回：

```json
{ "code": "KG.REVISION_CONFLICT", "params": { "resource": "type:Employee", "expected": 7, "actual": 9 } }
```

- 前端按 `code` 查 i18n 表渲染，`params` 用于占位替换。
- 状态值一律传枚举码，不传中文：

| 语义         | 枚举码                                         |
| ------------ | ---------------------------------------------- |
| 资源状态     | `DRAFT` / `PUBLISHED` / `ARCHIVED`             |
| 校验结论     | `PASS` / `VIOLATION` / `NA` / `NOT_RUN`        |
| 运行结果     | `SUCCESS` / `PARTIAL` / `FAILED` / `CANCELLED` |
| 关系映射模式 | `FK` / `JUNCTION` / `ASSOCIATIVE`              |
| 连接状态     | `CONNECTED` / `DISCONNECTED`                   |

- 错误码总表维护在后端（`app/core/error_codes.py`，M0 落地）与前端 i18n 码表**双向对齐**，CI 校验 key 集合一致。

## L3 · 领域语义内容（本项目特有）

用户在本体里创建的资源必须支持双语：

| 字段                | 是否翻译   | 说明                                                 |
| ------------------- | ---------- | ---------------------------------------------------- |
| `name`（机读名）    | **不翻译** | PascalCase，全局唯一，IRI 由 `namespace + name` 推导 |
| `label_i18n`        | 双语 JSONB | `{ "zh-CN": "员工", "en-US": "Employee" }`           |
| `definition_i18n`   | 双语 JSONB | 资源的自然语言定义                                   |
| 命名空间与 IRI 模板 | 不翻译     |                                                      |

规则：

- 中文必填、英文可选；英文缺失时 UI 标注「未翻译」，导出时在缺失语言上不生成该字面量，不伪造。
- 导出 Turtle / JSON-LD 时输出多语言字面量：

```turtle
:Employee rdfs:label "员工"@zh-Hans, "Employee"@en .
```

- **迁移自 demo 的数据天然是双轨**（`{ zh: '员工', name: 'Employee' }`）：`zh` 升为 `label_i18n['zh-CN']`，`name` 直接作为英文标签默认值。

## 实施时点

- **M0**：建 L1/L2 骨架（语言包、错误码、`"$t"` 规范、lint 规则）。
- **M1**：随实体类型/关系库落地 L3 双语字段。

理由：i18n 是横切能力，事后补会牵动全部组件——与 IRI 治理（H-03）同理。
