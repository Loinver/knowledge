# 测试约定

## 1. 分层

| 层       | 工具                 | 位置                      | 覆盖什么                                   |
| -------- | -------------------- | ------------------------- | ------------------------------------------ |
| 后端单元 | pytest               | `server/tests/`           | 领域服务、IRI 治理、映射编译、版本冻结     |
| 后端集成 | pytest + httpx       | `server/tests/`           | API 行为、错误码、并发冲突（409）          |
| 语义     | pytest + Turtle 夹具 | `server/tests/semantics/` | SHACL 报告结构、A08 推理状态切换           |
| 前端单元 | `node --test`        | `web/src/**/__tests__/`   | 布局算法、图谱过滤组合、纯函数             |
| 契约     | OpenAPI diff         | CI                        | 接口变更可感知、破坏性变更拦截             |
| E2E      | Playwright（M3 起）  | `e2e/`                    | 8 步主流程、失败保护、证据追溯与响应式检查 |

运行 `make test-e2e`（或 `pnpm test:e2e`）。Playwright 会启动隔离的 FastAPI/Vite 服务，使用临时元数据库和 `samples/enterprise_demo.sqlite` 的临时副本；不要连接或清理开发数据库。首次运行需执行 `pnpm exec playwright install chromium`。测试固定使用 8000 / 5173 端口，不复用已运行的开发服务器。

## 2. 必测断言（P0，缺一条不算完成）

1. **幂等性**：同一批次重复运行，实体 IRI 集合、关系数、隔离数完全一致。
2. **失败保护**：零产出或严格策略下判失败，**当前结果集指针不移动**，可切回上一成功运行。
3. **结果集切换**：任意历史成功运行可设为当前，切换后图谱与证据随之改变。
4. **证据追溯**：任一条事实可反查到来源连接、表、行键、字段、运行批次。
5. **版本冻结**：上游资源升级后，已发布本体/映射的引用版本不变。
6. **关联实体不被去重**：同一对实体的两次业务关系（两条参与记录）分别保存、分别可见。
7. **四态不失真**：未接入推理器时 A08 返回 `NOT_RUN`，而非 `PASS`。

## 3. 从 demo 迁移的回归基线

`demo/tests/*.cjs` 的断言已在 prototype 阶段踩过坑，**迁移而非重写**：

- `knowledge-graph.test.cjs`：邻域 1/2 度展开、隐藏类型不得作为不可见桥接点、派生边与关联实体的过滤组合、`all` 模式含孤立节点 → 迁到前端 `node --test`。
- `onto-merge.check.cjs`：本体列表/设计视图的结构完整性、模板来源、命名空间规则 → 迁到前端 `node --test` 与后端集成测试。

迁移时**保留原断言意图**，不要因为「现在的实现方式不同」就删掉断言。

## 4. 规则

- 测试用中文描述可以，但测试函数名用英文 snake_case + `test_` 前缀。
- 夹具数据一律脱敏（`example.org`、虚构信用代码）。
- 抽取/图谱相关测试**不得依赖执行顺序**，每次运行自建数据与 results。
- 新增 SQL/迁移，必须能在空库上重放成功（`alembic upgrade head`）。
